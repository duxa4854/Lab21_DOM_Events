## Краткое описание работы

Целью данной лабораторной работы является создание простого веб-приложения "Список задач" (TODO List) с использованием чистого JavaScript, HTML и CSS. Приложение позволяет пользователю добавлять новые задачи, отмечать их как выполненные и удалять ненужные элементы. Работа включает в себя инициализацию Git-репозитория, верстку интерфейса, стилизацию компонентов и написание логики взаимодействия с DOM.

## Описание (что изучили)

В ходе выполнения работы были освоены следующие навыки и технологии:

- **Работа с DOM:** Поиск элементов (`getElementById`), создание новых узлов (`createElement`), добавление их на страницу (`appendChild`).
- **Обработка событий:** Назначение обработчиков на клики кнопок ("Добавить", "Удалить", "Выполнено") и нажатие клавиши Enter.
- **Манипуляция классами:** Динамическое изменение стилей через добавление/удаление CSS-классов (например, зачеркивание выполненной задачи).
- **Git и GitHub:** Инициализация репозитория, создание коммитов, привязка удаленного репозитория и отправка кода (`push`).
- **Структура проекта:** Организация файлов проекта (HTML, CSS, JS) и ведение документации.

## Структура проекта

Проект состоит из следующих основных файлов:

- `index.html` — Главная страница проекта.
- `todo.html` — Разметка для списка задач (основной контейнер, форма ввода, список `<ul>`).
- `style.css` / `todo.css` — Стили для сброса отступов, оформления контейнера, кнопок и состояний задач (выполнено/не выполнено).
- `main.js` / `todo.js` — Логика приложения:
  - Функция `updateCounter()` — обновление счетчика задач.
  - Функция `createTaskItem()` — генерация HTML-элемента для новой задачи.
  - Функция `addNewTask()` — обработка ввода и добавление задачи в список.
- `img/` — Папка для скриншотов выполнения этапов работы.
- `README.md` — Документация проекта.
